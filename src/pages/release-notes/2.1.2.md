# Release 2.1.2 Available

![Joshua-Trees-haiku](/releases-2.1.0.jpg)

## Release Notes

Apache Ozone 2.1.2 is a maintenance release on top of Ozone 2.1.1 with bug fixes and stability improvements.

## Notable Fixes

### [HDDS-15578](https://issues.apache.org/jira/browse/HDDS-15578) — InvalidStateTransitionException can crash SCM

SCM no longer crashes from uncaught InvalidStateTransitionException during container state updates.

---

### [HDDS-15665](https://issues.apache.org/jira/browse/HDDS-15665) — Datanode transaction iterator race condition

Fixed a race condition in the datanode transaction iterator that could cause already-deleted transactions to be loaded and reprocessed after a flush.

---

### [HDDS-14577](https://issues.apache.org/jira/browse/HDDS-14577) — MISSING_METADATA_DIR when marking container UNHEALTHY

Fixed handling when container metadata directory is missing during container state updates on the datanode.

---

### [HDDS-14989](https://issues.apache.org/jira/browse/HDDS-14989) — Follower SCM datanode server starts before Ratis catch-up

Follower SCM nodes now defer starting the datanode protocol server until the state machine has caught up with the leader's committed log entries.

---

### [HDDS-15791](https://issues.apache.org/jira/browse/HDDS-15791) — EC RECOVERING container data loss after idle scrub

Fixed EC offline reconstruction data loss when idle RECOVERING containers were scrubbed and auto-recreated as partial CLOSED replicas.

---

### [HDDS-16175](https://issues.apache.org/jira/browse/HDDS-16175) — usedNamespace charged on every hsync re-commit

Fixed incorrect namespace accounting when the same key is re-committed via hsync.

---

### [HDDS-15475](https://issues.apache.org/jira/browse/HDDS-15475) — containerMap is not threadsafe

Fixed a thread-safety issue in the datanode container map.

---
