# Release 2.2.2 Available

<!-- cspell:ignore Develocity -->

![Katmai-haiku](/releases-2.2.0.jpg)

## Release Notes

Apache Ozone 2.2.2 is a maintenance release on top of Ozone 2.2.1 with bug fixes and dependency updates.

## Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

### Fixed

- Treat renaming an FSO file to itself as a no-op. ([HDDS-16779](https://issues.apache.org/jira/browse/HDDS-16779))
- Preserve the container state update path used during upgrades. ([HDDS-16169](https://issues.apache.org/jira/browse/HDDS-16169))
- Avoid updating the container delete transaction ID when appending to the SCM delete log. ([HDDS-15634](https://issues.apache.org/jira/browse/HDDS-15634))
- Allow repair tools to load RocksDB OPTIONS files written by newer RocksDB versions. ([HDDS-17144](https://issues.apache.org/jira/browse/HDDS-17144))
- Complete certificate inspection futures when a request passes inspection. ([HDDS-17030](https://issues.apache.org/jira/browse/HDDS-17030))
- Improve validation of multipart upload IDs and part numbers in OM requests. ([HDDS-17161](https://issues.apache.org/jira/browse/HDDS-17161), [HDDS-17162](https://issues.apache.org/jira/browse/HDDS-17162))
- Return `INVALID_REQUEST` for invalid replication configurations in bucket property and key creation requests. ([HDDS-17299](https://issues.apache.org/jira/browse/HDDS-17299))
- Validate the key prefix and container ID when importing a container. ([HDDS-17182](https://issues.apache.org/jira/browse/HDDS-17182))

### Changed

- Upgrade Jackson to 2.21.7. ([HDDS-16644](https://issues.apache.org/jira/browse/HDDS-16644))
- Upgrade Netty to 4.1.139. ([HDDS-17085](https://issues.apache.org/jira/browse/HDDS-17085))
- Upgrade the Develocity Maven extension to 2.6.0. ([HDDS-16713](https://issues.apache.org/jira/browse/HDDS-16713))
